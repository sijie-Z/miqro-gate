# 管理员手册

> 面向系统管理员（`SYSTEM_ADMIN`）。左侧管理导航共七组，**分组即架构**：
> 模型管理 · 访问与授权 · 用量与配额 · 成本管理 · 可观测性 · 安全与配置 · 集成管理。
> 每节格式：**操作路径 → 关键字段 → 例子 → 注意**。部署/升级/备份属于运维动作，见 [../operations-runbook.md](../operations-runbook.md)。

## 0. 每日/每周巡检清单（先看这个）

| 频率 | 看哪里 | 看什么 |
|---|---|---|
| 每日 | 总览 / 缓存收益 | 异常事件、失败率、缓存省钱趋势 |
| 每周 | 成本报表 → 账单对账 | 上游实付 vs 网关观测成本、对账差异 |
| 每周 | 配额规则 | 谁在接近阈值（预警走 Webhook / 也可在列表看百分比） |
| 按需 | 审计日志 / 内容留痕 | 操作留痕与（如已开启的）内容留痕 |
| 按需 | 供应商 / 上游凭证 | 凭证健康（最近验证）、余额来源列 |

## 1. 模型管理

### 1.1 供应商（产品目录 + 模型目录 + 在线调试）

- **路径**：模型管理 → 供应商。
- 每行是一个「供应商产品实例」（如 `deepseek-payg-api`），列含：协议、接入地址、实现状态、余额来源。行内：
  - **接入文档**：直达官方端点/资料（代码仓 `docs/provider-catalog.md` 对应章节）；
  - **模型目录**：查看该产品的模型清单——「探测模型」从供应商官方拉取；没有公开模型列表接口的，按上游真实 `model` 名手工补录（例：`deepseek-chat`）；
  - **试调**：用该产品首个生效凭证发一条真实消息（≤256 token，正文不落库），验证链路。
- 实现状态徽章（已文档化/已实现/已验证…）悬停有解释；**「已验证」需要真实凭证契约测试**，未验证的产品不建议承载生产流量（详情页警告已写明，用于生产前请用真实凭证完成验证）。

### 1.2 订阅

- **路径**：模型管理 → 订阅。
- 一个订阅 = 某产品下的一套额度/席位安排；团队套餐在行内「席位」里管理成员与席位分配（例：GLM 团队版按席位、腾讯企业版多 Key 共享池）。

### 1.3 上游凭证（真实 Key 保险库）

- **路径**：模型管理 → 上游凭证 → 录入凭证。
- 关键字段：「API 密钥」= 供应商官网申请的 Key（例 DeepSeek `sk-…`），加密保存、**不回显**；保存后点「验证」让网关真实调用供应商确认有效性。
- 行内「更多 ⌄」：测试密钥（候选密钥指纹比对，不落库）、轮换（新密钥立即生效、旧版本宽限期退役）、版本历史、停用。
- **注意**：删除/停用前先看是否有授权引用（列表有计数），凭证一旦从快照移除，关联虚拟密钥立即无法完成请求。

## 2. 访问与授权

### 2.1 用户

- **路径**：访问与授权 → 用户。
- 新建用户 → 生成**一次性临时密码**（关闭弹窗前交付给本人）；「编辑」改显示名；「重置密码」重新签发临时密码（旧会话失效）；「禁用」立即停登录并踢出现有会话（可逆）。
- 例：外部同事离场 → 先「禁用」，确认无遗留后将项目成员移除。

### 2.2 团队 / 项目

- 团队 = 组织标签（N:M，可一人多团队）；**项目 = 权限载体**（授权、虚拟密钥都挂项目）。
- 项目有「路由标签」（如 `core-ai`）：成员建 Key 时自动生成后缀，用于按项目路由；**被引用后不可清空**。
- 每个项目行内「成员」抽屉增删成员——用户必须至少属于一个项目才能建 Key。

### 2.3 授权（Grant）

- **路径**：访问与授权 → 授权。
- 一条授权 = **项目 × 上游凭证 × 供应商产品 × 模型范围**。新建流程：选项目 → 选凭证 → 勾选模型（可从官方目录拉取、或走已验证的目录）。
- 收缩模型范围**立即生效**（快照秒级刷新）；「禁用」授权即整体收回。

### 2.4 审批中心

- **路径**：访问与授权 → 审批中心。
- 用户提交的模型申请在此处理：「通过」把模型并入该 Key 的授权（立即生效）；「驳回」需填理由。
- **注意**：给已轮换/吊销 Key 的历史申请会返回明确指引（请改为驳回）——不要硬批。

### 2.5 API 消费者（机器身份）

- **路径**：访问与授权 → API 消费者。
- 面向外部系统：新建消费者 → 一次性展示 API Key（或配置 **JWT 公钥**，行内「凭证」列有徽章）。「能力作用域」含 `billing:read`（计费查询接口）、`mcp:call`（MCP 数据面）等，**默认全拒，须显式勾选**。
- JWT 支持设置/轮换/移除公钥；轮换宽限与原键重叠以便无感切换。

## 3. 用量与配额

### 3.1 用量报表

- **路径**：用量与配额 → 用量报表。
- 维度切换（项目/用户/团队/模型/供应商）、时间范围、请求时间线（含超长上下文的截断标记）；请求级明细可导出（CSV）。

### 3.2 配额规则

- **路径**：用量与配额 → 配额规则。
- 规则 = 作用域（用户/项目）× 指标（Token / 请求次数 / 成本）× 周期（日/周/月/年）× 阈值 × **动作**：
  - **仅预警（默认）**：到达阈值发 Webhook 告警，**不阻断**请求；
  - **超限拒绝**：到达 100% 后网关对该作用域返回 429，配额重置或提高限额后自动恢复。
- 例：给测试账号设 `请求次数 / 日 / 2000 / 仅预警`；给对外演示项目设 `成本 / 月 / 500 元 / 超限拒绝`。
- **注意**：软限流不会丢数据——命中缓存的请求不计配额的规则口径以列表「口径」列说明为准。

### 3.3 导出任务 / 用量删除

- **导出任务**：大数据量导出的异步任务与下载（含对账/调整等级标记）；
- **用量删除**：按时间窗口**物理删除**原始用量（删除请求本身与审计链永久保留）——删除后对账与成本报表同步变化，操作前先导出备份。

## 4. 成本管理

- **成本报表**：按调用方/项目/模型维度看成本构成与「网关观测成本 vs 上游实付」；
- **账单对账**：上传供应商 canonical JSONL 账单 → 生成四态报告（一致/差异/缺失/多计）；
- **缓存收益**（响应缓存 ROI）：总请求、L1/L2 命中、命中率、节省金额与等效折扣——判断缓存策略是否值得继续；
- **定价**：按（产品、模型、Token 类型）维护每百万 Token 单价（CNY）。单价是**不可变快照**：改价即追加，历史成本不重算。「从价格源同步」拉公开价格索引（USD）按汇率换算。新模型未定价时成本显示「未定价」，录价后自动入账。

## 5. 可观测性

- **审计日志**：全部管理动作（谁、何时、对什么、结果），含 from/to 变更明细；支持按动作/目标/时间过滤。
- **MCP 访问日志**：MCP 数据面逐调用记录（工具名、消费者、TTFB、结论）——仅元数据。
- **内容留痕**：**默认关闭**的独立能力。开启后，网关会把请求/响应正文加密落库（可设最大截断字节数），用于内容审核场景；查看/导出本身会被审计。隐私边界：不开则永不留存正文。开启属合规决策，请与法务确认后再启用。

## 6. 安全与配置

- **全局配置**：运行时可调项（例：响应缓存开关等）——改动有审计；
- **告警规则**：阈值 → Webhook 通道；支持测试发送；
- **Webhook 端点**：URL + 签名密钥（用于校验 `X-Signature`）；投递有重试与投递记录；
- **部署信息**：当前版本、环境地址（排查时报给运维）。

## 7. 集成管理

- **MCP 服务**：注册已有 MCP Server（Streamable HTTP / SSE）→ 工具清单（同步/手工/导入）逐个启停 → 访问控制（**服务级模式：开放/仅名单/名单外**，叠加**单工具覆盖**）→ 健康检查（默认 30s 探 `/health`）→ 韧性策略 → 手动上下线。「接入信息」提供 `streamableHttpUrl` / `sseUrl` 给封闭客户端使用；页顶「接入指引」有全流程。
- **智能体（Agent）**：为 Agent 绑定出口凭证（必须 ACTIVE），追踪 Agent 维度用量；
- **服务管理**：内部服务注册与健康检查；
- **技能库管理**：上传 Agent Skills 技能包（公开可见）并配置团队/项目下载授权。

## 8. 多环境与合规实践（推荐做法）

- **环境隔离**：演示/测试/生产分实例部署，各自独立的凭证与配额；
- **最小权限**：给每个业务线单独建项目与授权，不要共享一把 Key 跨业务；
- **凭证轮换**：上游凭证与虚拟密钥季度轮换；泄露时第一时间「停用」而非删除（可追溯）；
- **审计留档**：每月导出一次审计日志与成本报表归档；
- **内容合规**：涉及内容审核需求时才开启「内容留痕」，并同步配置消费端（见 [../retention-consumer.md](../retention-consumer.md)）。
