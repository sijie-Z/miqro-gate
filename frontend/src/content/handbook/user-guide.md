# 普通用户手册

> 你在控制台能看到的左侧导航：**总览 · 我的密钥 · 用量 · 技能库 · 模型申请 · 资料**。
> 每节格式：**在哪里 → 怎么做 → 例子 → 注意**。

## 1. 总览

登录后的第一屏。问候卡显示你的关键数字，下方是密钥概览与最近动态。

- 例：想确认今天用了多少 → 看问候卡右侧的统计 chips；想知道哪把 Key 最活跃 → 下方密钥卡片的「近 7 天用量」。

## 2. 我的密钥（最常用）

### 2.1 列表怎么读

| 列 | 含义 |
|---|---|
| 名称 | 你起的名字；点标题下小字是掩码（`mqk_live_…8f2a`），用于肉眼比对 |
| 用途 | 声明标签，不影响功能 |
| 允许模型 | 这把 Key 能调的模型 |
| 状态 | 可用 / 已停用 / 轮换中 / 已吊销 |
| 缓存 | 响应缓存开关（省 token，同请求秒回） |
| 创建时间 / 用量 | 「用量 · 近 7 天」列显示最近消耗 |

顶部可按状态筛选、按名称/项目/前缀搜索。

### 2.2 创建一把新 Key

右上「创建虚拟密钥」→ 填写（字段含义见 [quickstart.md](quickstart.md) §2）→ 创建 → **密钥仅显示一次**，立即保存。

> 例：给笔记本和台式机各建一把（`claude-code-笔记本` / `claude-code-台式机`），便于分开看用量、单独吊销。

### 2.3 日常操作（行内「更多 ⌄」菜单）

| 操作 | 说明 | 注意 |
|---|---|---|
| 接入 CC Switch | 打开弹窗，复制深链，在 CC Switch 里一键导入 | 最省事的接入路径 |
| 使用示例 | Claude Code 的三平台环境变量写法，一键复制 | 见 [quickstart.md](quickstart.md) §3-B |
| 轮换 | 生成新密钥；**新密钥立即生效，旧版本进入宽限期后退役** | 轮换后立刻更新所有客户端；旧 Key 宽限期后 404 |
| 重命名 | 只改显示名，不影响调用 | 常用于标注重用途 |
| 停用 / 启用 | **软停用**：绑定与授权原样保留，随时恢复 | 客户端表现为 404（无效 Key 统一语义） |
| 吊销 | 不可逆。列表保留记录但密钥永久失效 | 误吊销只能新建 |

> 轮换的完整语义（宽限期、版本历史）见 [../virtual-key-lifecycle.md](../virtual-key-lifecycle.md)。

### 2.4 一条请求的归属（跨项目场景）

一把 Key 默认绑定你创建时选的项目。若你参与了多个项目、想让同一把 Key 按工作目录自动归属，安装本机 `miqro-context` Agent（零配置，按仓库/目录映射判定）；或由客户端显式带 `X-Miqro-Project-Id` 头。详见 [developer-guide.md](developer-guide.md) §归属 与 [../activity-context-design.md](../activity-context-design.md)。

## 3. 用量

「用量」只统计**你名下 Key** 的消耗。

- **筛选**：时间范围、模型、Key；
- **汇总**：请求数、Token（输入/输出/缓存）、延迟；「用量趋势」卡支持 Token/请求/延迟三个视角；
- **明细**：逐条请求（时间、模型、Token、延迟、状态）——不含提示词与回答正文（设计如此）；
- 数字入账有几分钟延迟；对不上时先看「用量删除」是否被管理员清理过历史（管理员操作）。

## 4. 模型申请

当你想用一个当前授权**没覆盖**的模型时：

1. 「模型申请 → 新建申请」，选择你的 Key、填目标模型与理由（例子：「编码任务需要更强推理模型：deepseek-v4-pro」）；
2. 管理员在「审批中心」处理；通过后**立即生效**，无需重建 Key；
3. 状态在列表实时可见（待审批 / 已通过 / 已驳回+理由）。

注意：给**已吊销/轮换退役**的 Key 提交的申请会被系统拒绝（提示改为驳回）——先确认 Key 状态为「可用」。

## 5. 技能库

公司内部技能目录（Anthropic Agent Skills 格式包）：全部技能对登录用户可见，**下载权限按团队/项目授权**。

- 被授权 → 行内「下载」；未授权 → 提示联系管理员开通；
- 技能包版本会更新，下载前看列表里的版本号与更新时间。

## 6. 资料（账号与安全）

- **改密码**：修改后其他设备上的会话会被同时撤销，当前会话保持有效；
- **退出其他会话**：一键撤销除当前浏览器外的全部登录（例：怀疑账号在共享电脑登录过）；
- **上次登录 / 当前会话**：核对异常登录；
- **界面偏好**：右上齿轮（界面设置）——主题色、菜单主题、页面说明开关、自动锁屏（0/5/15/30 分钟）、菜单宽度、内容宽度；这些偏好只影响你自己的浏览器。
- **语言**：右上用户菜单可切 简体中文 / English。

## 7. 常见问题（速查）

- 新 Key 调不通？→ 先看 [quickstart.md](quickstart.md) §卡住了 的对照表；
- 想看「这笔账记给谁」？→ 「用量」汇总卡按分组维度查看（按项目/用户/团队），明细行核对「密钥」「供应商」列，归属规则见 [developer-guide.md](developer-guide.md) §归属；
- 更多问题 → [faq.md](faq.md)。

> 需要管理员视角的说明（供应商怎么接、配额怎么配、告警怎么设）？见 [admin-guide.md](admin-guide.md)。
