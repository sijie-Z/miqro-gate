## 一分钟认识 MiQroGate

```text
你的工具/应用 ──(虚拟密钥 mqk_live_… + 网关地址)──▶ MiQroGate 网关 ──▶ 真实供应商（DeepSeek/通义/Kimi/GLM/…）
```

- **对使用者**：拿到一把「虚拟密钥」和网关地址，像用官方 API 一样用它——协议原样透传，客户端零改造；
- **对管理员**：真实供应商 Key 集中加密托管，谁在用、用了多少、花了多少，全部进账本；
- **隐私**：默认**不保存**提示词与模型回答；「内容留痕」是显式开启的独立功能（见管理员手册）。

## 三条典型路径

**普通用户**：登录 → 「我的密钥」创建一把 Key → 按「接入」指引填进 CC Switch / Claude Code → 用起来 → 在「用量」看自己的消耗。

**管理员**：接供应商（「供应商」页确认产品 → 「上游凭证」录入真实 Key → 验证）→ 邀请成员加入项目 → 需要时在「审批中心」处理模型申请 → 在「成本报表 / 用量报表」对账。

**开发者**：读 [developer-guide.md](developer-guide.md) 的端点与示例；存量系统接入的三种姿势（开放客户端 / 可注入配置 / 完全封闭走 MCP）见 [../client-onboarding.md](../client-onboarding.md)。

## 约定

- 示例中的 `https://<网关地址>` 替换为你们部署的实际地址（门户登录页同一域名）；
- 示例密钥形如 `mqk_live_…`，**仅在创建时显示一次**，请立即保存到密码管理器；
- 「模型名」示例统一用 `deepseek-flash`，实际以你们「授权」中允许的模型清单为准（「我的密钥」创建时会列出）。
