# 常见问题（按症状查）

> 找不到对应条目？先确认三件事：**Key 状态**（我的密钥列表）、**网关地址**（门户同域名）、**模型名**（`GET /v1/models` 返回的清单）。

## 登录与控制台

**Q：登录后被要求「设置新密码」？**
首次登录（或管理员重置后）必须改密，临时密码随即作废。改完其他设备需要重新登录，当前会话不受影响。

**Q：用着用着跳回登录页？**
空闲 30 分钟或会话满 12 小时后需要重新登录（安全设计）。被「锁定屏幕」不会退出——解锁即可继续。若服务正在重启，会出现「服务不可用」重试页，点重试即可，**不需要重新登录**。

**Q：页面显示「页面出错了」卡片？**
这是兜底错误页。先点「重试」；反复出现把卡片里的错误信息发给管理员（版本更新后残留的旧页面通常刷新一次即好）。

## 密钥与接入

**Q：新建的 Key 复制时只显示一次，没保存怎么办？**
无法再次显示。到「我的密钥」行内「更多 ⌄ → 轮换」生成新密钥，更新客户端后用新 Key（旧 Key 宽限期后自动退役）。

**Q：为什么客户端报 401？**
按顺序查：①密钥是否完整（`mqk_live_` 开头，前后无空格）；②Key 是否被停用/吊销（状态列）；③客户端配置的字段是否是「Auth Token/API Key」而不是别的字段名。

**Q：报 404 且提示密钥无效，但 Key 明明存在？**
两种常见情况：①你用的是**轮换前的旧密钥**（轮换后旧值只会短暂宽限）；②`/v1` 面设计上对无效密钥统一返回 404（防枚举），别把它当「地址写错」——核对密钥值。MCP 面同一场景返回 401。

**Q：报 403 / 提示模型不可用？**
模型不在该 Key 的授权范围。去「模型申请」提交，管理员批准后立即生效；MCP 场景检查消费者是否勾了 `mcp:call`。

**Q：Claude Code / Claude Desktop 走 CC Switch 还是直连？**
两种都行：CC Switch 负责「多供应商切换 + 非 Claude 模型角色映射 + 跨协议转换」；直连（改 `ANTHROPIC_BASE_URL`）最简。注意本网关**不做跨协议转换**——协议转换发生在 CC Switch 侧。

**Q：一把 Key 能不能给多个项目用？**
可以（创建时多选项目）。用量归属：默认记首个/唯一项目；跨项目想自动区分，装 `miqro-context` Agent 或带 `X-Miqro-Project-Id` 头。

## 用量与费用

**Q：刚发的请求，用量页为什么没有？**
入账有几分钟延迟；先刷新看。若对账历史被管理员「用量删除」清理过，那一窗口的记录会消失（审计链仍在）。

**Q：成本显示「未定价」？**
该模型还没有价目快照。管理员在「定价」录入单价后自动入账，历史用量按录入后口径计算。

**Q：响应变快了、Token 也少了？**
可能命中了响应缓存（同 Key 显式开启时）。响应头 `X-MiqroKey-Cache: L1/L2` 可确认；「缓存收益」页能看整体节省。

**Q：429 配额超限？**
该作用域配置了「超限拒绝」规则且已到 100%。等周期重置，或请管理员提额/改成「仅预警」。

## 管理员视角

**Q：「探测模型」失败？**
常见原因：该产品没有公开的模型列表接口（按官方文档手工补录即可）、凭证未验证/已停用、供应商侧网络不通。探测失败不会破坏现有目录。

**Q：新凭证录入时「验证」失败？**
先确认该 Key 在供应商官网能用（用 curl 直连官方验证一次）；再核对产品/端点是否匹配（同一供应商不同 Plan 的 Key 不互通——按「接入文档」对照）。

**Q：怎么把某把旧 Key 彻底停掉？**
「停用」是软停用（可恢复）；「吊销」不可逆。泄露场景：先「停用」止损，确认新 Key 已上线后再「吊销」。

**Q：删除供应商/凭证前要注意什么？**
列表有引用计数。删除/停用会让关联虚拟密钥立即无法完成请求（快照移除是秒级生效）。

**Q：内容留痕会保存我的提示词吗？**
**只有管理员显式开启**后才会（加密落库、可设截断上限），且查看本身的动作会进审计。默认关闭时网关不保存任何正文。

## 数据与合规

**Q：审计日志能删吗？**
审计链设计上不可删（用量可以物理删除，审计保留）。这是报备/合规要求的一部分。

**Q：备份恢复怎么做？**
运维动作，见 [../operations-runbook.md](../operations-runbook.md)；演练脚本与验收见 [../testing-and-acceptance.md](../testing-and-acceptance.md)。

**Q：平台单点登录还没通？**
需要平台侧先开通 OAuth client（申请单模板见 [../platform-oauth-onboarding.md](../platform-oauth-onboarding.md)），未开通期间用本地账号。
