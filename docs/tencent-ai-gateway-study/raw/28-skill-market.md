# 135253 (doc 135253)


本文旨在引导您在 Skill 市场中搜索与下载已发布的 Skill。功能说明Skill 是 Agent 的原子能力单元，用于描述“这个 Agent 能做什么”。对外它对应 A2A 协议 AgentCard 中的 AgentSkill 对象（id/name/description/tags/examples），对内是 AI 网关侧一条可复用的能力配置记录。同一个 Skill 可被多个 Agent API 复用，修改一次即可同步生效。前提条件已通过 Skill 管理创建 Skill。浏览与搜索 Skill 市场当前 Skill 管理页面新建的 skill 默认同步到 Skill 市场。1. 登录 AI 网关控制台，在左侧导航栏选择实例列表。2. 单击目标 AI 网关实例 ID 进入实例详情页。3. 在左侧导航栏选择 AI 能力市场 > Skill 市场。4. 页面以卡片形式展示当前租户内所有已发布的 skill，每张卡片包含名称、描述、Tags（最多展示 3 个）、创建人与 ZIP 包上传标识。5. 可通过以下方式筛选：| 筛选项 | 取值范围 | 说明 |
| 关键词搜索 | 最长 60 个字符 | 对 Skill 名称、ID、描述做模糊匹配，大小写不敏感 |
| 标签筛选 | 从已有 Tags 中选择 | 按标签精确过滤，为真实过滤能力（非仅视觉切换） |
