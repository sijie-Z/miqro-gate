# 135489 (doc 135489)


在配额管理页新增默认配额策略页签，支持配置全局默认配额策略:全局默认配额策略:配置启用开关、默认配额类型、默认统计周期、默认限额。保存后仅影响新建消费者，已有消费者配额不受影响。新建消费者自动分配:全局策略已启用时，新建消费者后自动按全局策略创建配额规则。前提条件已创建 AI 网关实例，且实例状态为运行中。已创建至少一个消费者。操作步骤步骤1：进入默认配额策略1. 登录微服务平台控制台，在左侧导航栏选择 AI 网关进入实例列表。2. 在实例列表页面，单击需要配置的网关实例的“ID”，进入该网关实例的基本信息页面。3. 在左侧导航栏选择配额管理。4. 单击默认配额策略。步骤2：配置默认配额策略1. 在 默认配额策略 页签，展示以下提示文案:“默认配额策略仅对保存后新创建的消费者生效，已有消费者配额不受影响”“修改策略后，仅后续新建的消费者会采用新策略，已自动分配的配额规则保持不变”“关闭策略后，已自动分配的配额规则不会被删除，但新消费者不再自动获得配额”2. 当前策略状态以表格形式展示:| 字段 | 说明 |
| 启用状态 | 未启用 / 已启用。 |
| 配额类型 | Token 数量 / 请求次数。 |
| 统计周期 | 按日 / 按周 / 按月。 |
| 限额 | 配额上限值。 |3. 单击配置策略按钮，打开“配置默认配额策略”弹窗。4. 参考下表完成配置。| 参数 | 是否必选 | 说明 |
| 启用状态 | 是 | 开关，控制是否对新建消费者自动分配配额。 |
| 配额类型 | 是 | 下拉单选，可选 请求次数 / Token 数量。 |
| 统计周期 | 是 | 下拉单选，可选 按日 / 按周 / 按月。 |
| 配额上限 | 是 | 数值输入，例如 1000000 表示 100 万 Token。 |步骤：查看配额规则1. 单击配额规则页签，查看全部配额规则列表。2. 配额规则表格展示以下列:| 列名 | 说明 |
| 资源类型 | 如消费者。 |
| 资源 ID/名称 | 消费者 ID / 名称。 |
| 配额类型 | Token 数量 / 请求次数。 |
| 配额上限 | 配额上限值。 |
| 已用 | 已使用量。 |
| 使用率 | 使用百分比。 |
| 统计周期 | 按日 / 按周 / 按月。 |
| 启用状态 | 已启用 / 未启用。 |
| 创建/修改时间 | 创建/最近修改时间。 |
| 操作 | 编辑、删除。 |3. 单击新建配额规则可手动为特定消费者创建配额规则。参数说明自动创建配额规则属性| 属性 | 取值 | 说明 |
| 消费者 | 新创建的消费者 | 与本次新建消费者绑定。 |
| 配额类型 | 全局策略配置 | 继承“默认配额策略”中的配额类型。 |
| 统计周期 | 全局策略配置 | 继承“默认配额策略”中的统计周期。 |
| 限额 | 全局策略配置 | 继承“默认配额策略”中的配额上限。 |
| 启用状态 | 已启用 | 自动创建的配额规则默认启用。 |
