## 学习总结

### A. 可直接借鉴（纯元数据治理，不读正文）

1. **MCP 两级访问控制**：Server + Tool 级 Allow/Deny/None ACL、消费者组批量授权、Tool 规则在 Server 基础上进一步收窄 → 对应我们的虚拟 Key 授权模型
2. **Agent 服务**：凭证/能力与对外入口分离；引用密钥按供应商+资源类型过滤；不可变标识 + 绑定后禁改禁删 + Skill 快照语义
3. **Tools 版本管理**：配置快照与运行配置分离；仅语义字段版本化；生效版永不裁剪；幂等回滚
4. **MCP 路由规则**：default 兜底路由（不可改删）+ 高优先级自定义；匹配 Path/Host/Method/Header（不读正文）；冲突实时校验
5. **模型探测**：凭证 + Endpoint 连通性校验（GET /v1/models），失败不阻断可手动录入
6. **Tools 重试**：非幂等方法重试需显式确认门禁；首字节前才重试；默认关闭
7. **Tools 熔断**：三态熔断 + 最小请求数防误判 + 慢调用阈值 < 后端超时校验 + 熔断期间跳过重试
8. **MCP 日志**：纯元数据访问日志 + 固定字段前缀（aigw.mcp.*）——「不存正文」范式
9. **Tools 分组**：引用不复制 + 组内名称唯一 + AutoPrefix 冲突处理；单组默认 10 个控 Token
10. **消费者默认配额**：全局模板 + **创建时快照复制**（改模板不惊动存量）；关闭不删已分配；手动规则覆盖默认
11. **消费者组**：组级启停开关（一键熔断整团队）；删除依赖检查；改属性与管成员解耦
12. **成本分析**：用量（事实）与金额（单价依赖）分层；多维度 Tab；缓存命中 Token 单列
13. **操作记录**：元数据审计 + JSON 变更明细；凭证类保留期建议更长防删
14. **Skill 管理/市场**：SKILL.md 解析只回填空字段；多 Agent 复用、修改全局生效；对外映射 A2A AgentSkill
15. **服务来源**：Source→同步目录→被模型/MCP 服务引用分层；密码走凭证管理

### B. 需 ADR/反转决策才可做（读正文，与产品「不读正文/不改写」冲突，仅合规对照）

- 参数改写（06：转发前改 Body/Query，一层键、字符串值，改写在缓存查询之后）
- 流量镜像（07：按比例复制请求采集 TTFT/TPOT/Token/成本）
- 数据脱敏（08：日志脱敏依赖包体采集 + 转发脱敏占位符替换，fail-closed）
- 日志包体采集（26：记录 Prompt/Completion，可作反面案例/合规降级选项）

### C. 架构核对结论

- 密钥/服务/API 三层 ≈ 我们的凭证→产品实例→虚拟 Key（方向正确；「轮询多密钥」刻意不做）
- MCP 接入地址模型 `/mcpservers/{name}/mcp`
- 分布式会话缓存（Redis + TTL 1800s）→ 衔接「V1 不部署 Redis、留缓存 SPI」决策
- Prometheus 按 Route 粒度开关采集，避免热路径开销
