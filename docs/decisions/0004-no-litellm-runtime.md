# ADR-0004：不采用 LiteLLM 运行时

- 状态：Accepted
- 日期：2026-07-17

## 决策

生产系统不依赖 LiteLLM 包、Proxy 或镜像。Bifrost 也不作为生产运行依赖，只作为行为参考。

## 原因

系统集中保存高价值真实 API Key，供应链风险权重极高。LiteLLM 在 2026 年 3 月发生过 PyPI 凭证窃取供应链事故。客户也需要 Java 技术栈完整交付。

## 后果

- Java 团队拥有全部数据面代码。
- 必须自行维护供应商透明适配与契约测试。
- 可以参考宽松许可证项目的设计，但生产依赖必须经过许可证和安全审查。
